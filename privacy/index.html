Winfu 隐私政策

更新日期：2026-10-28

Winfu 是运行在用户自己电脑上的桌面播放器。开发者不运营任何服务器，也不收集、接收或存储用户的任何数据。

Google 用户数据

  • 申请的权限：只申请 Google Drive 只读权限 https://www.googleapis.com/auth/drive.readonly。
  • 用途：列出用户选定文件夹中的视频、字幕、nfo 和图片文件（名称、大小、修改时间、校验值），并在本机播放和读取这些文件。仅用于向用户提供片库和播放功能。
  • 存储：文件列表保存在用户电脑上 Winfu 的数据目录里；访问令牌只在内存中使用，刷新令牌用 Windows 数据保护（DPAPI）加密后保存在本机设置中。视频内容不落盘，只在播放时经本机端口（127.0.0.1）流式读取。
  • 共享：为了识别影片并显示海报和简介，Winfu 会把从文件名解析出的片名和年份发送给 The Movie Database（TMDB）。用户自己开启相应功能时，也会把片名发送给所选的在线字幕服务或 AI 翻译服务，并把观看记录同步到用户自己的 Trakt 账号。除此之外不与任何第三方共享 Google 用户数据，不用于广告，也不出售。
  • 不写入：Winfu 不会修改、删除或上传 Google Drive 中的任何文件。
  • 撤销与删除：在 Winfu 里退出 Google 账号会删除本机保存的令牌；也可以随时在 Google 账号的第三方访问权限页面撤销授权。卸载 Winfu 时可以选择删除整个数据目录。

Winfu 使用和转移从 Google API 获得的信息时，遵守 Google API 服务用户数据政策，包括其中的"有限使用"要求。

其他数据

片库、观看进度、设置和日志都只保存在用户电脑上。Winfu 没有统计、遥测或崩溃上报。

联系

如有问题，请通过 Google 授权页面上显示的开发者邮箱联系。

Winfu Privacy Policy

Last updated: 2026-10-28

Winfu is a desktop player that runs on the user's own computer. The developer operates no servers and does not collect, receive or store any user data.

Google user data

  • Scope: Winfu requests only read-only Google Drive access, https://www.googleapis.com/auth/drive.readonly.
  • Use: to list the video, subtitle, nfo and image files (name, size, modification time, checksum) in folders the user selects, and to read and play those files on the user's computer. It is used only to provide the library and playback features to the user.
  • Storage: the file list is kept in Winfu's data folder on the user's computer. Access tokens are used in memory only; the refresh token is encrypted with Windows Data Protection (DPAPI) and stored in the local settings. Video content is not written to disk; it is streamed through a local port (127.0.0.1) during playback.
  • Sharing: to identify titles and show posters and descriptions, Winfu sends the title and year parsed from file names to The Movie Database (TMDB). When the user turns on the corresponding features, titles are also sent to the chosen online subtitle or AI translation service, and watch history is synced to the user's own Trakt account. Google user data is not shared with anyone else, is not used for advertising and is never sold.
  • No writes: Winfu never modifies, deletes or uploads files in Google Drive.
  • Revocation and deletion: signing out of Google in Winfu deletes the locally stored tokens. Access can be revoked at any time on the Google Account third-party access page. Uninstalling Winfu offers to delete its whole data folder.

Winfu's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other data

The library, watch progress, settings and logs are stored only on the user's computer. Winfu has no analytics, telemetry or crash reporting.

Contact

For questions, contact the developer at the email address shown on the Google consent screen.
